# DSA4Kids Heldenbogen

Digitaler Charakterbogen (Pragmatiker) für Kinder, optimiert für Tablets.
`index.html` im Browser öffnen (oder auf GitHub Pages hosten) und über "Zum Home-Bildschirm" ablegen.

- **Erstellen**: Werte frei einstellen, Punktebudgets werden angezeigt.
- **Spielen**: Steigern kostet automatisch Abenteuerpunkte nach den Regeln des Bogens.
- Mehrere Helden, Daten lokal im Browser; "Sichern"/"Laden" exportiert/importiert JSON.
